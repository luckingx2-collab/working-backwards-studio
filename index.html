    04 · 실행으로 연결

    T11에서 확인할 것, 담당 후보, 기한을 정하고 결과를 내보내세요.

    각 단계의 무료 AI 도움에서 초안·다듬기·검토를 요청할 수 있습니다. AI는 기기에서 실행되며 모델 다운로드가 필요하며 CPU 또는 GPU 모드를 선택할 수 있습니다. 예시는 가상 자료입니다. 자동 저장은 기기·브라우저별로 유지되므로 다른 기기로 옮길 때는 JSON 백업·복원을 이용하세요.

    작업을 안전하게 이어가기

    다른 기기에서 이어 쓰려면 백업 파일을 내려받아 복원하세요.

    복원하거나 새로 시작하면 현재 작업을 대체합니다. 먼저 백업을 보관하세요. HTML 다운로드에는 입력한 내용이 포함되지 않아 빈 양식으로 배포할 수 있습니다.

    무료 AI 도우미 기기 내 실행

    API 키·호출 요금 없이 사용하는 공개 모델처음에는 모델 파일을 다운로드합니다(수백 MB~수 GB). Wi-Fi 사용을 권장합니다. 다운로드에 인터넷이 필요하며 기기의 메모리·배터리를 사용합니다. 입력 내용은 외부 추론 서버로 전송하지 않습니다. 작은 모델의 한국어 응답은 부정확할 수 있어 검토가 필요합니다.

    모델 준비 전

    자동 덮어쓰기 없이 ◐ 초안으로 저장합니다.

    Transformers.js 3.8.1 / WebLLM 0.2.87 · Qwen2.5 Instruct · CPU 호환 모드는 GPU 없이 실행하며 GPU 모드에는 WebGPU가 필요합니다. 앱 내부 브라우저에서 실행되지 않으면 Chrome/Edge에서 열어주세요.
