# Working Backwards Studio

한국어 고객 중심 기획 워크숍. 11개 단계를 따라 고객 이해부터 PR/FAQ와 실행 계획까지 작성합니다.

## 사용
GitHub Pages에서 접속하거나 index.html을 다운로드하여 Chrome/Edge로 여세요. 계정 가입과 API 키는 필요하지 않습니다.

- 입력 내용은 사용하는 브라우저에 저장됩니다. 다른 사용자와 공유되지 않습니다.
- 처음 방문하면 빈 워크숍으로 시작합니다. 예시 버튼으로 가상 자료를 살펴볼 수 있습니다.
- 결과 모아보기에서 Markdown, HTML 및 JSON 백업을 다운로드합니다.
- 무료 AI 도움에서 CPU 모델을 준비한 뒤 원하는 항목의 초안을 생성합니다.

## 무료 AI
Qwen2.5 Instruct를 기기 내에서 실행합니다. CPU 호환 모드는 Transformers.js 3.8.1, GPU 모드는 WebLLM 0.2.87을 사용합니다. 최초 실행에는 인터넷과 수백 MB~수 GB 모델 다운로드가 필요합니다. 속도·메모리 사용량은 기기에 따라 다르며 모든 모바일 환경을 보장하지 않습니다. 작은 모델의 한국어 출력은 검토가 필요합니다.

입력은 외부 추론 API로 전송하지 않지만 모델·실행기 다운로드 시 해당 제공자에 접속합니다. 생성 내용은 사용자가 반영하기 전 원문을 덮어쓰지 않습니다.

## 검증 범위
CPU 모델의 실제 생성, 선택 항목 반영, 새로고침 후 유지, Markdown/JSON 내보내기를 확인했습니다. GPU 경로 실제 추론과 모든 모바일 기기 호환성은 미검증입니다.

## 정적 배포
Settings → Pages → Deploy from a branch → main / (root). 빌드 도구나 서버가 필요하지 않습니다.

## 브랜드 및 외부 구성요소
ETEVERS CI는 https://group.etevers.com/kor/about/ci.html 의 자료를 사용했습니다. 브랜드 자산과 모델·라이브러리는 각 권리자의 조건을 따릅니다. 이 저장소가 브랜드 자산에 대한 별도 재사용 권리를 부여하지 않습니다.

## T8 실제 만화 이미지 생성
- 공개 모델: FLUX.1 schnell (Apache 2.0), 제작사 공식 Space: https://huggingface.co/spaces/black-forest-labs/FLUX.1-schnell
- 클라이언트: @gradio/client 2.7.2, 공식 /infer API.
- 공통 인물 묘사와 6컷 설명을 입력하고 외부 전송에 동의한 뒤 생성합니다. 이 세 가지 항목만 전송합니다.
- Hugging Face 토큰은 선택 사항이며 탭 메모리에서만 사용합니다. 서버·JSON·로컬 저장소에 기록하지 않습니다.
- 무료 데모의 할당량·대기열·로그인 제한이 있으며 무제한 무료 서비스가 아닙니다. 유료 API로 자동 전환하지 않습니다.
- 이미지들은 브라우저 IndexedDB에 보관하며 JSON 백업에는 포함되지 않습니다. PNG 또는 시각 보고서 HTML로 보관하세요.
- 공식 생성기에서 만든 그림을 컷별로 가져올 수도 있습니다.
- 2026-11-10 검증: API 연결 후 ZeroGPU quota exceeded 오류 확인. 실제 이미지 추론 성공은 미검증입니다. 이미지 저장·새로고침 복원·6컷 PNG 내보내기는 단색 테스트 이미지로 검증했습니다.
